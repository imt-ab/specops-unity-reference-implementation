# Specifications

This folder contains feature specifications and templates.

Structure:
`Assets/Project/Docs/Specifications/<feature>/`

- `SPEC.md`: goals, non-goals, requirements, and edge cases
- `CONSTRAINTS.md`: must / must not rules, budgets, and compatibility requirements
- `ACCEPTANCE.md`: testable acceptance criteria in Given / When / Then form

Template files live under `Assets/Project/Docs/Specifications/_templates/`.

Acceptance criteria must be testable.
