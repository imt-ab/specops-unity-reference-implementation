## Purpose

This document records architecture decisions that affect multiple
features and define the project's global technical direction.

**Rules:** - Decisions here are the authoritative record for
architectural change. - When a decision changes global invariants,
update `GLOBAL_CONSTRAINTS.md` accordingly. - Feature specs must
reference relevant ADR IDs when they depend on or introduce a decision.
